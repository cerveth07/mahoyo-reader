# 魔夜读本 · 全游戏版

完整解压发布包，关闭游戏。打开「魔夜读本安装器.exe」，确认游戏目录后点「安装读本」。安装器会同时装好小学馆《中日・日中統合辞書》。也可以点「浏览…」选择 WoH.exe。安装完成后从 Steam 启动游戏，在游戏设置里选择「日本語」。

如果使用单独提供的脚本安装包 mahoyo-yomibito-full.zip，完整解压后关闭游戏，双击「安装.cmd」，再从 Steam 正常启动《魔法使之夜》。在游戏设置中选择日语。安装器会查找 Steam 游戏库。游戏在其他目录时，可把实际游戏目录里的 `WoH.exe` 拖到「安装.cmd」上，卸载时拖到「卸载.cmd」。想先检查主程序版本，可在安装包目录运行 `.\Install.ps1 -GamePath '你的游戏目录' -CheckVersion`，该命令只读取文件。自定义路径可运行 `.\Install.ps1 -GamePath '你的游戏目录'`。支持 Windows x64 Build 13060638。安装器和 MOD 启动时均核对主程序，允许 PE 校验和与文件末尾证书表不同，其余原始字节须与该构建一致。这项检查只判断 MOD 的版本兼容性。其他构建和实际第三方整合包尚待实机验证。遇到其他来源的 d3d9.dll，安装器会说明冲突。

## 怎样阅读

日文按游戏的翻页与演出显示。中文小字在对应日文行的上方。行首有余宽时，中文会向右收约半个小字。注音后的续文从下一个可用位置起排。行间中文与独立译文卡里的中文使用 Noto Serif SC Medium。「对照」默认显示本页所有行间译文，推进剧情时，前文译文的字和描边会一起变淡。回指旧句时，所指译文会恢复到和新句一样清晰。把鼠标移到某句日文上停留约 0.25 秒，其他中文会暂时隐藏。有可靠的分句对应时，细金线标出所指分句，只显示对应部分；否则显示该句的完整译文。把鼠标移到正文外就恢复整页中文。点词取词时暂停此效果。悬浮球的「功能说明」可查各项用法。把鼠标停在普通汉字词上约 0.4 秒，可以看假名。只有读音的词用小气泡显示，有辞书形或释义的词用完整词卡。N1、已开启的 N2 和原作注音卡在指向时即显示。原作的特殊读法优先，并在需要时标明来源。

### 词卡中的读音与音调

| 提示 | 含义 |
| --- | --- |
| ⓪、①、② 等 | 日语词的音调型。⓪为平板型，①、②表示音高分别在第 1、2 拍后下降。并列数字表示源卡收录多个音调型 |
| 辞书重音 | 与词卡标示的辞书读音对应 |
| 名・自動3、他動1 | Anki 源卡的词类写法。名是名词，自動和他動分别是不及物和及物动词。数字 1、2、3 指动词分类。普通词卡用「名词」「动词」等中文名称 |

假名上方的金线从左到右显示每拍的高低，圈号有多个时取第一个。末端的小圆表示后接助词的音高，可用来区分平板型和尾高型。复合重音、辞书重音或读音不明确时仅显示原标记。

短译文有余宽时，相邻汉字之间会稍微留空。长译文优先使用原有字号和行宽，数字、标点和拉丁字母保留自然间距。

作者写的假名和傍点仍贴在日文上方。遇到注音，中文会在词界处分开，给注音两侧留白。逗号等句末标点能放下时，会跟前面的词留在一起。行首余宽不足时自动减小缩进。如果整句译文仍然放不下，可用独立的译文卡回读。

画面右侧的悬浮球是阅读入口。点一下悬浮球即可切换「对照」和「原文」，或打开生词本、收藏夹、离线词典。按住悬浮球可拖到顺手的位置。松开后记住位置，「复位悬浮球」可移回右侧。

功能说明、选词和补释义默认使用竖向窗口。生词本、收藏夹和最近查过默认在左侧列出条目，右侧显示释义、原句或译文。拖动窗口边缘把它缩窄，详情会移到列表下方。

首次打开读本会先显示外框并加载资料，关闭窗口后读本在后台保留。再次打开可直接查阅，关闭游戏或空闲满 30 分钟后读本退出。

在「原文」中，把鼠标移到想读的日文句子上停留 1 秒，就会在原位显示这一句中文。已有学习词卡的词优先查词，普通汉字词的小气泡可与行间中文同屏。翻页后需要重新移动鼠标。咏唱等特殊行框可用行尾的「查看译文」。模式选择立即生效，重开游戏会记住。习惯键盘的玩家也可按 F8 切换。

《罗宾有珠三千问》的对话气泡也支持逐行对照。中文随对应的日文出现，续到同一个气泡时可以连着读。鼠标移到第一章小红帽的比喻、第 1.5 章的英语童谣或第五章重复的拉丁文咏唱上，点行尾「查看译文」可读双关或中文句意。

### 给生词补释义

1. 指向有词卡的词，卡内底栏可「补释义」或「加入生词本」，也可直接「收藏原句」。词卡会给日文、行间中文和原作注音留出位置。想记没有词卡的假名时，点悬浮球的「点词取词」，再点一次原文里的任一假名。选词只对这一次点击生效，也可按 Esc 取消。
2. 选词窗口会按原文词界预选整个词。点「気遣って」的「て」也能选到完整词形，辞书形是「気遣う」。只标到合成词的一部分时，从卡内点「调整词界」。可选已识别的长词或短语，也可点「向左扩一词」「向右扩一词」或直接拖选。
3. 在「参考义项」里点选一项，按本句用法修改，也可直接输入「我的释义」。点「保存释义」后，遇到同词及能识别的活用形就可悬浮查看。只想记录一句的特殊用法时勾选「仅记在本句」。自由拖选若无法确定词界，会自动采用本句范围。
4. 再次遇到生词时，点「编辑释义」可改写或「记这条例句」。在「生词本」里可搜索、标为「已掌握」、重新标为生词或移除生词。「导出全部」可选 CSV 或 TSV，包含词条、读音、个人释义、状态和日中例句，每条例句一行。

### 最近查过

词卡或读音气泡实际显示满 0.8 秒后，打开读本的「最近查过」就能找到它。再次查看同一处的词会移到最前面，列表最多保留 500 条。选中词条可看释义和日中原句，点「加入生词本」补释义，记过的词在列表中显示「已记」。也可收藏原句、移除单条或确认清空。导出包含查看时间（UTC）、词条、读音、释义、剧情键、日文原句和中文译文。

### 收藏、批注和导出原句

把鼠标移到日文行上，点行尾书签保存整句。实心书签表示已经收藏，右上角的金点表示这句有批注。词卡展开时，改用卡内的「收藏原句」。在词卡编辑窗口点「收藏词和原句」，可在收藏里同时标出这个词。同一句里的多个词共用一条收藏。也可用 F9 收藏鼠标所指内容。点悬浮球的「收藏夹」或按 F10，按日文、中文、读音或批注查找，支持移除和撤销最近一次移除。「导出原句」可将所有收藏保存为 CSV 或 TSV，包含日文、中文、已标记的词与读音，最后一列是「批注」。

在原句详情的「批注」框输入文字。停笔 0.8 秒或移出输入框时自动保存，「已保存」会短暂显示。有批注的条目在列表第二行显示笔形图标。移除一条原句会保留它的批注，撤销移除或再次收藏该句即可查看。

### 选择离线词典

安装完成后，「补释义」即可离线查询小学馆《中日・日中統合辞書》。从悬浮球打开「离线词典」，可查看随附辞书或添加其他来源。「补释义」会自动从这些词典查找参考义项。

| 你手头的词典 | 使用方法 |
| --- | --- |
| 小学馆《中日・日中統合辞書》 | 随 MOD 安装并自动启用，无需下载、导入或安装 EBWin4。词卡中点「补释义」即可选择小学馆的参考义项。完整辞书原件位于游戏目录下 `mahoyo-learning/local/shogakukan.zip` 内的 `original/`。 |
| 可选 Tomoshi 日中词典包 | 点「导入词典」，选择发布包的 `可选词典/mahoyo-ja-zh-optional.zip`，保留这个内层 ZIP 即可。脚本安装包也支持把词典 ZIP 拖到「安装.cmd」上。约 599 KiB，含 14,398 个词形与读音组合，由 Tomoshi 日中数据按剧情用词筛选。 |
| 自己的 Yomitan 词典或词表 | 点「离线词典」里的「导入词典」，选择 Yomitan 词条 ZIP，或 UTF-8 TSV 文件。TSV 每行按「词条、读音、释义」用制表符分隔，可给一个词写多行义项。 |
| 自己的 EB/EPWING 电子辞书 | 点「关联本机词典」，选该辞书的 CATALOG 或 CATALOGS，按提示指定已有的 EBWin4.exe。这项功能供另有其他本机辞书的玩家使用。移动原词典后，重新关联新路径即可。 |

各词典的候选义项会标出来源。保存到词卡的是你最后选定或改写的释义。导入词典后，查词、记词和导出都可离线使用。

## 数据和设置

本版使用完整文本表，含本篇、番外及文本表中的附加条目，共 24,134 个键。20 个原作留白键保持空白。字幕作用在日文剧情文本层，游戏菜单、图片内文字、视频和语音沿用原作。译文采用澄空 Steam 移植文本。已核实的一对错序译句按原文话者重新配对。另有 16 处中文校订，包括卢恩咏唱的音译及番外的跨句衔接。N1/N2 词条取自 egg rolls《JLPT N1–N5 一万词》的 Anki 牌组。其余读音由 Sudachi 分词和词典生成，作品专名采用原作注音，并单独校订了部分多音词和术语。

剧情译文使用随读本附带的 Noto Serif SC Medium（500）。对照模式的行间中文、原文模式的悬停句译、分句译文，以及生词本例句和收藏原句的中文都用同一字体。悬浮球菜单、按钮、词卡释义和读本其他中文界面优先使用 Windows 宋体（SimSun）。日语词头与假名优先使用 BIZ UDP 明朝，原作日文和振假名沿用游戏字形。

关闭游戏，编辑游戏目录下的 `mahoyo-learning/settings.ini`，下次启动生效。

| 选项 | 默认值 | 效果 |
| --- | --- | --- |
| enabled | 1 | 设置为 0 可关掉读本 |
| include_n2 | 0 | 设置为 1 开启 N2 完整词卡。关闭时，含汉字的 N2 词也可查假名 |
| inline_translation | 1 | 1 为对照，0 为原文，游戏中按 F8 切换 |
| record_lookups | 1 | 词卡或读音气泡显示满 0.8 秒后记入最近查过。0 为暂停记录，既有记录保留 |
| parallel_highlight | 1 | 悬停时只显示对应句或分句的译文，移开恢复。0 为关闭对应高亮 |
| ui_japanese_face | 可选，留空时优先使用 BIZ UDP 明朝 | 在 `[study]` 中指定已安装的日文字体族名，供游戏词卡和 StudyBook 使用。找不到时沿用默认顺序 |
| orb_position | 10000,8600 | 悬浮球在画面内的相对横、纵位置，范围各为 0 到 10000，横向 0 和 10000 表示贴边，拖动后自动保存 |
| reserve_ruby_space | 1 | 为行间中文保留原生注音槽。当前版本始终保留该空间，旧值 0 会按 1 处理 |

收藏夹存放在游戏目录下的 `mahoyo-learning/favorites.tsv`。复制该文件即可备份或迁移。含个别异常行时，收藏夹仍会显示可读取的条目。首次成功修改前会保留原始文件副本 `favorites.tsv.bak`，后续备份会另外保存。

个人释义和例句保存在 `mahoyo-learning/personal-words.dat`。重新安装或升级会保留它们。导入的词表放在 `mahoyo-learning/dictionaries/`，启用的词典及本机路径记在 `mahoyo-learning/dictionary-sources.xml`。查词历史保存在 `recent-lookups.tsv`，原句批注保存在 `sentence-notes.tsv`，都位于 `mahoyo-learning/`。关闭游戏并等待读本退出后，备份这两份文件、生词本、收藏夹和 `settings.ini`。在另一台电脑安装同版读本后，将备份放入对应目录；目标已有学习记录时，先另存一份。迁移词典后，在新位置重新导入或关联。

## 卸载

使用图形安装器时，先退出游戏，再在同一窗口点「卸载读本」。生词、收藏、批注和设置会保留。

使用脚本安装包时，关闭游戏，双击「卸载.cmd」。安装器核对归属后将 DLL 改名禁用，保留设置和恢复文件。再次启动即可使用原版。安装、升级与卸载均不需要改写存档或游戏资源包。
