# Windows 全游戏版公开发布核验

## v2026.11.20.1 番外「衛兵」词卡修订

适用 Steam Windows x64 Build 13060638。玩家 ZIP 为 52,076,083 字节，SHA-256 为 `ea94722bf77952d3b0603aa3833481ea784430cd86e1980a7b8e5f6990a90fa7`。

- 从三份固定输入重新构建。逐键解码前后两版的 24,134 条记录，唯一差异在第 19734 键、UTF-16 区间 `[16,18)` 的「衛兵／センチネル」。该词卡保留「原作」来源，词性为「名词」，中文释义为「卫兵、哨兵。」，音调为「①」。发布语料中此词形与原作注音的组合共一处。
- 中文义项据随包小学馆《中日・日中統合辞書》「衛兵」。音调据国立国语研究所《現代書き言葉UniDic》2025.12 的 `lex.csv`，词目 `センチネル-sentinel`、普通名词、lemma ID 168943、`aType=1`。[UniDic 官方归档](https://clrd.ninjal.ac.jp/unidic/back_number.html)
- 新版 `story.dat` 的 SHA-256 为 `3abadd75344a5c144d32b34571bf564f9ed58fada0c07367d602351cfa2f9003`。除记录该哈希的文件头外，选词索引与初版逐字节相同。小学馆辞书、可选 Tomoshi 词典及字体沿用原哈希。
- 在最新公开检出的源码中，从同版玩家 ZIP 重编，通过全量原生解码、GDI、D3D9 离屏阅读帧、读本与小学馆查词回归。D3D9 测试以实际语料建立本词的完整卡片纹理，验证①对应第一拍高、其余四拍及后接助词低，以及三个可操作的底栏按钮。
- 在隔离游戏副本中用初版读本写入一条已掌握的「衛兵」个人笔记。升级后，生词本、收藏、句子批注、最近查词及设置均与安装前逐字节一致。新版读本重新索引后仍能找到同一笔记 ID、释义、掌握状态和原句位置，继续编辑也只保留一条。新版原生读本直接读取初版笔记索引亦通过。安装事务测试仅检查隔离副本对应的游戏进程，用户会话中的游戏保持运行。
